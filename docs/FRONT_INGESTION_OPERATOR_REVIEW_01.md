# FRONT-INGESTION-OPERATOR-REVIEW-01

## Executive Summary

Created an operator review queue planner (`brain/ingestion_operator_review.py`) that consumes dry-run ingestion results and structures the human decision-making process for approving candidates to proceed to future controlled dry-run steps.

## Scope

This front structures the operator review queue for all ingestion candidates generated by the dry-run planner. It does NOT execute ingestion, does NOT read content, does NOT write to storage, and does NOT trigger any real actions.

## What This Front Does

1. **Reads dry-run results** from `brain/ingestion_dry_run.run_registry_dry_run()`
2. **Maps dry-run statuses to review statuses**:
   - `candidate` -> `pending_operator_review`
   - `operator_review_required` -> `pending_operator_review`
   - `blocked` -> `blocked`
   - `registry_only` -> `registry_only`
   - `invalid` -> `not_reviewable`
3. **Assigns allowed decisions** and default decisions for each item
4. **Generates immutable safety flags** documenting no execution occurred
5. **Validates** that no item claims real ingestion authorization
6. **Summarizes** the review queue by status

## What This Front Explicitly Does NOT Do

- **No ingestion execution** — content is never read or parsed
- **No semantic memory write** — `memory_write_executed` is hardcoded to `False`
- **No FAISS write** — `faiss_write_executed` is hardcoded to `False`
- **No network calls** — no requests, httpx, aiohttp, or urllib usage
- **No connector calls** — no external APIs invoked
- **No file I/O** — URIs are referenced but never read
- **No real approval** — `approve_for_future_dry_run` only prepares for a future dry-run step, NOT real ingestion
- **No promotion** — no knowledge is promoted to any storage

## Operator Review Contract

### Input
- `brain.ingestion_dry_run.run_registry_dry_run()` (6 records)

### Review Item Fields
- `review_id`: deterministic ID
- `source_id`, `source_type`, `uri`: from dry-run candidate
- `risk_level`, `allowed_mode`, `content_policy`: from dry-run
- `dry_run_status`: original dry-run status
- `residual_risk`: computed residual risk
- `requires_operator_approval`: from dry-run
- `planned_actions`, `blocked_reasons`: from dry-run
- `review_status`: mapped review status
- `allowed_decisions`: list of decisions operator can make
- `default_decision`: recommended default
- `safety_flags`: immutable assertions
- `approval_authorizes_real_ingestion`: always `False`
- `can_write_semantic_memory`: always `False`
- `can_promote_faiss`: always `False`

## Review Statuses

- **pending_operator_review**: Needs human review (candidates + operator_review_required)
- **blocked**: Rejected, not reviewable
- **registry_only**: Listed but no action needed
- **not_reviewable**: Invalid record

## Allowed Decisions

- **approve_for_future_dry_run**: Operator approves for future controlled dry-run step (NOT real ingestion)
- **reject**: Operator rejects the source
- **request_more_context**: Operator requests additional information
- **keep_blocked**: Maintain blocked status
- **no_action**: No action needed

## Safety Flags

All items carry immutable safety flags:

```json
{
  "ingestion_executed": false,
  "content_read": false,
  "memory_write_executed": false,
  "faiss_write_executed": false,
  "network_called": false,
  "connector_called": false,
  "promotion_executed": false
}
```
