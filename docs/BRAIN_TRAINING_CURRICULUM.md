# Brain Training Curriculum

Updated: 2026-06-12T19:10:30.941341+00:00

This curriculum converts verified operational incidents into auditable training artifacts. It is not semantic memory and it does not write to FAISS.

## Scope

- governed autonomy
- provider routing and quality discipline
- dry-run evaluation safety
- memory promotion governance
- chat readiness and operator-facing clarity

## Current Lessons

1. Kimi K2.5/K2.6 must be routed through Ollama Cloud tags unless a verified operator path says otherwise.
2. Empty provider responses are failures, not successful answers.
3. Training artifacts must remain separate from semantic memory until promotion gates pass.
4. Evaluation harnesses default to dry-run/read-only.
5. Autonomy cycles require explicit scope, safety, no-secret, and no-mutation gates.

## Promotion Lifecycle

candidate -> validated -> promoted_operational_lesson -> runtime guard -> semantic promotion candidate

Semantic promotion is deliberately not automatic. No semantic memory writes and no FAISS writes are allowed in this curriculum phase.
