# Leak Source Audit — Front 02

## Root cause

`finalizer.py` `build_finalizer_prompt()` sets `payload['required_format'] = ['Summary', 'Evidence used', 'Actions performed', 'Risks/gates', 'Next safe action']`. The LLM complies and produces `## Summary`, `## Finalización de Ejecución Agent V2`, `I'll finalize this Agent V2 run...`, etc.

## Flow

```
finalizer.py prompt (required_format array)
  → LLM produces structured sections
  → answer returned
  → langgraph_parity_runtime state['final_answer'] = answer
  → response_normalizer.py (identity guard only — no boilerplate strip)
  → api_adapter.py final_answer
  → dashboard_routes.py:368 content = data.get('final_answer')
  → UI shows boilerplate to user
```

## Leak patterns (generated by LLM following finalizer instructions)

- `## Summary`
- `## Finalización de Ejecución Agent V2`
- `## Finalización de Ejecución Agent V2 — Diagnóstico`
- `I'll finalize this Agent V2 run...`
- `The user requested...`
- `The user asked...`
- `This is an evidence-required diagnosis run...`
- `Requested vs scheduled vs executed`
- `LIVE TOOL EVIDENCE` / `MEMORY EVIDENCE`
- `Actions Performed` / `Evidence used` / `Risks/gates` / `Next safe action`

## Fix location

`response_normalizer.py` — add `sanitize_user_facing_content()` that strips finalizer boilerplate from `final_answer` before it reaches the chat UI. Conservative: only strips known patterns, preserves actual answers, code blocks, safety refusals.
